Penalty Game
Welcome to my Penalty Game repository. I developed this interactive football game using Scratch. My goal with this project was to create an entertaining penalty shootout experience while improving my visual programming, logical thinking, and game development skills.

About the Project
This game simulates the tension and excitement of a penalty shootout. I focused on creating smooth mechanics and an engaging user experience. By utilizing block-based coding, I managed the game logic, physics simulations, and user interactions to bring the football pitch to life.

Features
Interactive penalty shootout mechanics.
Real-time score tracking system to keep count of successful goals.
Engaging sound effects and visual animations that enhance gameplay.
Simple, intuitive controls designed for an enjoyable experience.

How to Play
To play the game, you will need the sb3 file included in this repository.
Go to the official Scratch website.
Click on Create at the top menu to open the editor.
Click on File at the top left corner, then select Load from your computer.
Choose the Penalty Game sb3 file from your computer.
Click the Green Flag to start the game and take your shot.

Technologies Used
I built this project entirely using Scratch. I utilized its block-based programming interface to handle all the game mechanics, variable tracking, sprite animations, and audio management.

Feedback and Contributions
Feel free to download the project, explore the code blocks, and make your own modifications. Examining the logic behind the game is a great way to learn, and I am always open to feedback. You can fork this repository or reach out if you have any suggestions to improve the game mechanics.
